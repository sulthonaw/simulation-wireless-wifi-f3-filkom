# Agent Rules & Guidelines

## Git Workflow
- **Git Push**: Agen dilarang keras menjalankan perintah `git push`. Proses push ke remote repository selalu dilakukan secara manual oleh pengguna (USER).
- **Git Commit**: Ketika pengguna meminta commit, buat pesan commit yang ringkas dan padat tepat dalam 1 (satu) kalimat deskriptif sesuai perubahan nyata yang dibuat, lalu langsung eksekusikan.
